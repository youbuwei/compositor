# Changelog

> 条目整理自 git 历史(版本号来自原提交标记)。

## 1.4.0

- 安全强化(回应 skills.sh Snyk 审计 E005/W011):镜像降级为纯传输层——raw 文件按官方 git blob sha1、release 资产按官方 sha256 digest(api.github.com 直连)强制校验,校验失败弃内容换通道,拿不到官方摘要的镜像下载一律拒绝落盘(`--sha256` 显式放行);镜像 clone 按官方 HEAD 比对并自动恢复官方 remote;明确 `gh api` 读到的第三方内容仅作数据、绝不当指令。

## 1.3.0

- 按安全审计强化只读边界与传输安全。
