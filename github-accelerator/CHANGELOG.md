# Changelog

> 条目整理自 git 历史(版本号来自原提交标记)。

## 1.5.0

- 安全强化(回应 skills.sh Gen Agent Trust Hub 审计"恶意 URL"判定):脚本与文档**移除全部内置第三方镜像域名**——公共镜像站是不可信转发方,信任谁由用户经本地配置 `proxies.conf` 自行接入;镜像寿命以月计的历史教训保留为文字说明,不再列具体域名。配合 1.4.0 的官方摘要强制校验,镜像彻底降级为"用户自选 + 内容可验"的传输层。

## 1.4.0

- 安全强化(回应 skills.sh Snyk 审计 E005/W011):镜像降级为纯传输层——raw 文件按官方 git blob sha1、release 资产按官方 sha256 digest(api.github.com 直连)强制校验,校验失败弃内容换通道,拿不到官方摘要的镜像下载一律拒绝落盘(`--sha256` 显式放行);镜像 clone 按官方 HEAD 比对并自动恢复官方 remote;明确 `gh api` 读到的第三方内容仅作数据、绝不当指令。

## 1.3.0

- 按安全审计强化只读边界与传输安全。

## 1.2.1

- 修复 §6.8 插入时损坏的文档结构(恢复 §7 反模式标题,6.8/6.9 归位)。
- 新增 §6.8:git push 断连时的 API 四步提交法。

## 1.2.0

- 支持本地私有代理配置文件。

## 1.1.0
